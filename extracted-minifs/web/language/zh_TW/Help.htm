    • WAN 連線類型
    • 依您 ISP 提供的資訊選擇適當的 WAN 連線類型。
    • 一般的
    • 選擇此類型做為一般的 IPv6 網際網路連線。
    • PPPoE
    • 若您的 ISP 使用 PPPoEv6 配置來配發位址並提供使用者名稱和密碼，請選擇此類型。
    • Tunnel 6to4
    • 若您的 ISP 使用 6to4 配置來配發位址，請選擇此類型。
    • 取得 IPv6 位址
    • 依您的 ISP 給予的資訊選擇自動或固定。
    • 位址
    • 路由器 WAN 介面的 IPv6 位址。
    • 前綴長度
    • 路由器 WAN 介面的 IPv6 前綴長度。
    • 預設閘道
    • 路由器 WAN 介面的預設 IPv6 閘道。
    • 使用與 IPv4 相同的 PPPoE 連線
    • 若與 IPv4 使用相同 PPPoE 連線，請選擇此類型。請在您選擇此選像之前確認您的 IPv4 WAN 連線為 PPPoE。
    • 使用者名稱/密碼
    • 您的 ISP 提供的使用者名稱和密碼。
    • 手動設定 DNS 伺服器
    • DNS 位址將被自動配發至路由器，您也可以手動設定需要的。
    • 主要 DNS / 次要 DNS
    • 輸入您 ISP 提供的主要/次要的 IPv6 DNS 伺服器位址。
    • 啟用前綴委託
    • 若由 ISP 的 DHCPv6 伺服器取得一前綴委派，請選擇此類型。LAN 中的客戶端將生成帶有此前綴的 IPv6 位址。
